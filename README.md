# Kindergarten Health Monitor (Система контроля здоровья воспитанников)

Профессиональное desktop-приложение для автоматизации работы медицинского кабинета в детском саду. Позволяет вести учёт заболеваемости, вакцинации, антропометрии и посещаемости воспитанников.

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)
![Tkinter](https://img.shields.io/badge/GUI-Tkinter-green)
![SQLite](https://img.shields.io/badge/DB-SQLite-lightgrey)

## 🚀 Возможности

*   **Учёт воспитанников**: Ведение личных дел, истории болезней и контактов родителей.
*   **Медицинские карты**: Фиксация диагнозов, прививок, медотводов и антропометрических данных (рост, вес, ИМТ).
*   **Мониторинг вакцинации**: Автоматическое выявление детей, нуждающихся в ревакцинации (например, от кори в 6 лет).
*   **Аналитика и отчёты**:
    *   Генерация PDF-справок (история болезни, карта прививок).
    *   Экспорт списков в Excel.
    *   Визуализация статистики (диаграммы заболеваемости, распределение по группам).
*   **Посещаемость**: Электронный табель учёта присутствия.

## 🛠 Стек технологий

*   **Язык**: Python 3
*   **GUI**: Tkinter (с использованием ttk для стилизации)
*   **База данных**: SQLite3
*   **Библиотеки**:
    *   `pandas`, `openpyxl` — экспорт данных
    *   `matplotlib` — построение графиков
    *   `reportlab` — генерация PDF
    *   `tkcalendar` — удобный выбор дат
    *   `Pillow` — работа с изображениями

## 📦 Установка и запуск

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/username/kindergarten-health.git
    cd kindergarten-health
    ```

2.  **Создайте виртуальное окружение:**
    ```bash
    python -m venv venv
    # Windows
    venv\Scripts\activate
    # macOS/Linux
    source venv/bin/activate
    ```

3.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Инициализация базы данных (опционально):**
    Чтобы заполнить базу тестовыми данными, запустите скрипт:
    ```bash
    python populate_db.py
    ```

5.  **Запуск приложения:**
    ```bash
    python main.py
    ```

## 🖥 Использование

### Главный экран
Слева расположен список детей с фильтрацией по группам и поиском. Справа отображается подробная информация о выбранном ребенке или формы добавления данных.

### Добавление записи о здоровье
1.  Выберите ребенка из списка.
2.  Перейдите на вкладку "Здоровье".
3.  Заполните форму (дата, тип записи, описание) и нажмите "Добавить".

### Генерация отчётов
На карточке ребенка нажмите кнопку `🖨 PDF` для сохранения полной выписки из медицинской карты.

## 🔒 Безопасность и данные
Все данные хранятся локально в файле `kindergarten.db`. Приложение поддерживает создание резервных копий через меню "Бэкап".
